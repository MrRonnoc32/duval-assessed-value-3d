# Duval County — Assessed Value (3D)

An interactive 3D map of every parcel in Duval County / Jacksonville, FL, extruded
by its 2025 assessed value. Built from Duval County Property Appraiser (DCPAO) open
data joined to the county parcel polygon shapefile.

**[▶ Open the live map](https://mrronnoc32.github.io/duval-assessed-value-3d/)**

## What you can do

- **Metric** — height/color by **total assessed value** or **assessed value per acre**.
- **Color by** — a value gradient, or discrete **land-use category** (DOR use code).
- **Basemap** — satellite imagery, streets, light, or dark, with optional place labels.
- **Height exaggeration / scale curve** — tune how dramatically value drives height.
- **Min value** — filter out low-value / vacant parcels.
- **Land-use slicer** — show/hide individual categories (single-family, commercial,
  industrial, institutional, parks, etc.); live parcel counts per category.
- **Hover** any parcel for its assessed value, acreage, $/acre, and land-use category.

## Data sources

- **Assessed value & land-use code** — DCPAO "Real Estate Combined" pipe-delimited
  export (row type `00001`: `SOH_VAL` field for assessed value, `DOR_CD` for use code).
- **Parcel geometry & acreage** — DCPAO `Parcel_Polygons` shapefile
  (Florida East State Plane, ftUS → reprojected to WGS84).
- 395,044 parcels rendered (parcels with assessed value ≤ 0 are dropped).

## Rebuilding the data

`parcels.json` is generated by [`build_parcels_json.py`](build_parcels_json.py),
which streams the DCPAO text file, joins on the `STRAP` key, simplifies each polygon
(3 ft tolerance), reprojects to WGS84, and writes a compact JSON. Point the paths at
the top of the script at your local copies of the DCPAO export and shapefile, then:

```bash
python3 build_parcels_json.py   # requires GDAL/OGR Python bindings
```

## Running locally

Because the page fetches `parcels.json`, open it through a local web server rather
than `file://`:

```bash
python3 -m http.server 8765
# then visit http://localhost:8765/
```
